# SmartAPI read-only REST groundwork

The Python adapter in `services/smartapi.py` has three explicit operations. Authentication, one-day historical request and one-instrument LTP quote use a fixed HTTPS host with redirects and ambient proxies disabled. Responses are bounded to 512 KiB, the socket timeout is seven seconds, requests are spaced at least five seconds apart within a client, and each client has a 30-call lifetime budget. A provider throttle imposes a 60-second cooldown. These are local guardrails. They are not claimed as account limits or cross-process throttling.

The app remains offline by default. For a future authorized smoke test, use a separate process and confirm account entitlements and approved egress directly with Angel One. The explicit `GOLOK_SMARTAPI_AUTHORIZED=1` environment flag, `GOLOK_SMARTAPI_KEY`, `GOLOK_SMARTAPI_PUBLIC_IP`, `GOLOK_SMARTAPI_LOCAL_IP`, and `GOLOK_SMARTAPI_MAC` enable the real transport for that process. Provide client code, PIN and current TOTP interactively in memory and avoid shell history. A session authentication failure requires a fresh explicit login. The client stores the JWT in memory. Diagnostics expose sanitized status codes and a local receipt time. The LTP endpoint lacks a verified observation time in this implementation, so the quote is never marked fresh. Historical rows retain provider event timestamps and cannot be automatically imported as closed or point-in-time data.
