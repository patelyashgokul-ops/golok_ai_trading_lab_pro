# SmartAPI read-only REST groundwork

P03 adds an administrator-only configuration and opt-in authentication wizard. See [provider operations](PROVIDER_OPERATIONS.md) for its local environment and timeout rules.

The Python adapter in `services/smartapi.py` has three explicit operations. Authentication, one-day historical request and one-instrument quote use a fixed HTTPS host with redirects and ambient proxies disabled. Responses are bounded to 512 KiB and the socket timeout is seven seconds. A standalone adapter without a shared reservation callback spaces requests by five seconds and caps its lifetime at 30 calls. Odoo applies the database-local 60-second quota per operation. A provider throttle imposes a 60-second cooldown. The app's local guardrails do not establish provider account limits.

The app remains offline by default. Confirm account entitlement and registered egress with Angel One before testing. Use [the owner setup](OWNER_ACTION_REQUIRED.md) to opt in locally, supply fresh timestamped authorization and run diagnostics. Historical sync uses the current worker's read-only client, and requires the explicit opening-timestamp contract. The first recorded receipt supports descriptive use. For LTP, freshness is unknown without an observation timestamp. The FULL quote path only classifies freshness when the provider supplies a time with an explicit offset.
