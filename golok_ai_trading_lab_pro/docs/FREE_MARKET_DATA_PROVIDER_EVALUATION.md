# P07 market data provider evaluation

Reviewed 24 November 2026. No paid plan, account or feed was activated.

| Source | Access and rights finding | P07 decision |
| --- | --- | --- |
| NSE CM UDiFF | The official reports page identifies the modern daily file. Publication does not establish archival, automation or optimization rights for this project. | Validate authorized local uploads. The tested row was synthetic. |
| NSE MCP | Official endpoints serve cash-market and Bhavcopy queries for an informational scope, with commercial use restrictions. | Keep fixture protocol regression. Production research acquisition and storage remain disabled. |
| Yahoo Finance | The yfinance maintainers identify personal-use limits. Applicable project rights are unconfirmed. | Denied by the source capabilities registry. |
| Angel One | Existing P06 adapter is read-only. Entitlement, approved egress and archival rights are required. | Keep explicit authorization and fixture mode. No real request in P07. |
| Upstox | The owner reported inactive account segments. No active entitlement or terms for this project were established. | Disabled source entry. |
| Operator-held CSV | Requires a documented local permission review covering query, display and ongoing internal storage. | Generic market CSV now demands an effective company review. |

Official sources checked for P07 include the format catalogue, report listing and usage policy. The linked NSE XLSX was not readable in the research browser. The implementation uses a strict header profile exercised with synthetic rows and awaits comparison to an authorized exchange file.
