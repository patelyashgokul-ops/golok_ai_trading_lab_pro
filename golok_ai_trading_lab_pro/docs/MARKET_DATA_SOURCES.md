# Market data sources

Odoo supports legacy CSV and calendar-bound temporal CSV. A temporal row preserves opening time, close time, declared source publication, and local ingestion time. Label all synthetic data explicitly. User declarations and calendar review do not establish broker entitlement, vendor timestamp reliability or universes free of survivorship bias.

SmartAPI fixture data is confined to test tooling. The read-only REST service and offline diagnostics are separate from production storage. Automated ingestion, authenticated market data, and streaming require authorized verification and a vendor timestamp contract.
