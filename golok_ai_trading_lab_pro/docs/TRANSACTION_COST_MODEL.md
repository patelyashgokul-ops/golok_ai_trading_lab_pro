# Hypothetical transaction costs

Risk Managers create immutable company-scoped JSON tariff revisions. Enter the per-side categories expected by the Decimal calculator in `services/simulation.py`. Valid periods are half-open. Missing or overlapping categories veto a synthetic fill. P03 accepts hypothetical tariffs only, and the fixture values have no historical or current fee authority. See the executable schema in [spec.json](../tests/fixtures/p02/spec.json). Verified rates, official account reconciliation and partial-fill fee allocation remain pending.
